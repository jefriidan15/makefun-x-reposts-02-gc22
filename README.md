## Run it

```sh

```

## Entry

`POSTS.json` at the repository root names the entry's posts. It currently holds a placeholder address: **do not submit this commit**. The real post addresses arrive once the posts are made on X from one public account — each a quote of, or a direct reply to, a different post of make.fun's pool (every @makefunai post from https://x.com/makefunai/status/2125053632605196760 on), carrying make.fun or @makefunai plus the play code `makefun-urchin-timber-sled`. Score: 2 points per repost and per quote, 1 point per like, summed over all posts; top 50 share $500.
